**HangulSync는 현재 Mac과 Mac 사이의 한·영 입력 상태를 맞춰 주는 macOS 앱입니다. Windows와의 동기화 지원은 공식 README에서 확인되지 않습니다.**

[HangulSync GitHub — 기능과 사용법](https://github.com/catgarret/HangulSync) · [다운로드](https://github.com/catgarret/HangulSync/releases)

## 어떤 문제를 해결하나

원격 데스크톱을 쓸 때 로컬 Mac과 원격 Mac의 입력 언어가 다르면 한글이 `ㅎㅏㄴㄱㅡㄹ`처럼 자소 단위로 분리되거나 원치 않는 단축키가 실행될 수 있습니다. HangulSync는 두 Mac의 입력 상태를 동기화해 이런 문제를 줄이는 도구입니다.

## 주요 기능

- 한쪽에서 한·영을 바꾸면 다른 Mac에도 입력 상태를 전달합니다.
- 같은 네트워크에서는 기기를 자동 탐지하고, 다른 네트워크에서는 Tailscale을 활용할 수 있습니다.
- Jump Desktop, 화면 공유, AnyDesk 등 원격 접속 앱이 실행 중일 때만 동기화하도록 설정할 수 있습니다.
- 메뉴바에서 동기화 일시정지·재개와 로그인 시 자동 실행을 관리합니다.

## 시작 방법

두 Mac에 앱을 설치하고 실행한 뒤 한쪽에서 기기를 찾습니다. 양쪽의 연결 코드를 확인하고 승인하면 페어링됩니다. 구체적인 설치와 연결 방법은 저장소의 최신 안내를 따릅니다.
